## Por que está aqui

O livro que ensina a escrever Python idiomático em vez de Python-com-sotaque-de-outra-linguagem. A tese é que a linguagem tem um modelo de dados coerente, e que dominar os métodos especiais é o que separa quem usa Python de quem fala Python.
